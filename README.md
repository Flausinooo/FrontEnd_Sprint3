# Photo Profile

Projeto desenvolvido para a Challenge JOVI 2026.

## Sobre

O Photo Profile é uma Landing Page que apresenta uma solução para personalizar a experiência fotográfica dos usuários.

Através de perfis criados com base nos interesses de cada pessoa, o sistema pode sugerir configurações e modos de câmera mais adequados para cada situação.

## Tecnologias

- HTML5
- CSS3
- CSS Grid
